# 豐收記帳 (HarvestBook PWA) 🌾💰

> 一款支援多帳本切換（日常生活、股票投資專戶）、資料 100% 本地隱私保存、具備離線快取與安裝能力的現代化 Progressive Web App (PWA) 記帳應用程式。

---

## ✨ 核心特色

1. **📚 多帳本管理 (Multi-Ledger)**
   - 自由建立不同專屬帳本（如：**日常開銷**、**股票投資**、**期貨交易**、**出國旅遊** 等）。
   - 各帳本獨立統計、獨立幣別（如 NT$）、色彩標記與專屬圖示。
   - 頂部導航列支援一鍵快速切換，也支援總覽全部帳本的累計結餘。
   - **🔗 合併帳本功能 (Merge Ledgers)**：可自由將任意來源帳本的所有記帳明細一鍵遷移合併至目標帳本中，並支援自動清理已合併的來源帳本。

2. **📈 股票投資專屬支援**
   - 專門為投資族打造，支援股票買進、股票賣出、現金股息、券商手續費與證交稅。
   - 股票明細支援記錄標的代號（如 `2330 台積電`、`0050`、`NVDA`）、股數、每股單價。
   - 提供「自動計算總額」功能（股數 × 單價 + 手續費）。
   - 投資資產專屬統計：買進總額、賣出總額、累積股息、標的資金佔比圓餅圖。

3. **📊 統計圖表與分析**
   - 支出分類互動環形圖 (Donut Chart)，動態計算各類佔比。
   - 收入 vs 支出長條對比圖。
   - 月度快速切換（本月、上個月、下個月、歷史月份）。
   - 月預算進度條與超支警示。

4. **📱 PWA 跨平台離線支援**
   - **Service Worker 離線快取**：即使在飛航模式或無網路環境下依然能順暢記帳。
   - **可安裝至手機/桌面主畫面**：
     - **iOS (iPhone/iPad)**：使用 Safari 開啟網頁 ➔ 點擊底部「分享」按鈕 ➔ 選擇「加入主畫面」。
     - **Android (Chrome)**：點選右上角三點圖示 ➔ 選擇「安裝應用程式」或「加到主畫面」。
     - **桌面版 (Chrome/Edge)**：網址列右側會出現安裝圖標，可直接安裝為獨立桌面視窗。

5. **🔒 隱私與資料管理**
   - **100% 本地儲存**：資料儲存於瀏覽器 LocalStorage，無後端伺服器收集，免登入、無廣告、極速啟動。
   - **防窺模式 (Privacy Toggle)**：頂部提供眼睛按鈕，在公共場合記帳可一鍵隱藏所有金額顯示。
   - **Excel / CSV 試算表匯出與匯入 (支援台灣券商股票對帳單 .xlsx)**：
     - **直接支援【對帳單.xlsx】**：自動辨識券商對帳單格式（成交日、商品代號名稱、現買/現賣、成交價、數量、手續費、證交稅、應收應付金額），300+ 筆交易 1 秒直接自動歸入【股票投資】帳本！
     - **匯出**：支援匯出「單一帳本」或「全部帳本合併」，內建 UTF-8 BOM，在 Excel 開啟繁體中文絕對不亂碼。
     - **匯入**：支援一鍵匯入外部整理的 `.xlsx` 或 `.csv` 檔案，智慧識別日期、金額、收支類型、分類、股票標的與備註，自動追加合併。
   - **JSON 完整備份與還原**：可隨時匯出整機備份檔，跨裝置轉移或定期儲存。
   - **一鍵清空記帳記錄**：隨時一鍵清空示範資料，保留個人帳本配置。

6. **⚡ 版號機制與強制即時更新 (Cache Buster)**
   - **版號與建置戳記**：每次打包自動注入語意化版號（如 `v1.0.0`）與建置時間，並產生未快取的 `version.json`。
   - **GitHub Pages 即時更新檢測**：背景自動比對伺服器版本，一旦發現遠端發布新版本即彈出更新橫幅提醒。
   - **一鍵強制更新 (Force Update)**：頂部導航列版號標籤與帳本設定頁均提供強制更新按鈕，徹底清除 Service Worker 與 Cache Storage 並重整，保證獲取最新網頁程式碼，且**絕不遺失本地記帳資料**。

## 🚀 本地開發與預覽

```bash
# 安裝依賴項
npm install

# 啟動本地開發伺服器
npm run dev

# 打包生產版本
npm run build

# 本地預覽打包結果
npm run preview
```

## 🌐 部署至 GitHub Pages 設定指引

本專案已配置好自動化工作流 `.github/workflows/deploy.yml`。

### 啟用步驟：
1. 將專案推送到 GitHub 的 `main` 分支。
2. 前往 GitHub 該 Repository 的 **Settings** ➔ **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 **`GitHub Actions`**。
4. 推送後，GitHub Actions 將會自動執行建置並發布到 GitHub Pages。
5. 完成後即可透過 `https://<你的GitHub帳號>.github.io/Money/` 開啟並安裝至手機主畫面！
